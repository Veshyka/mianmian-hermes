## 以后怎么用

改完定制件（插件/脚本/技能/变更记录）就跑一条：

```bash
bash scripts/publish_push.sh "这次改了什么"
```

它会依次：白名单拷贝 → 脱敏 → 自带复核扫描 → **独立复核** → 提交 → 推 main。
任一道闸不过就地中止，绝不推。公开前用 `bash scripts/publish_push.sh --check` 只跑闸不推。
