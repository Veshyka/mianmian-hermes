# 变更 2026-10-03：主动私聊改成「沉默时长升概率」的纯脚本斜坡

**触发**：主人问「你给她加主动发言了吗，私聊/群聊，其实我想到一个有意思的办法，不是有时候光固定时间有点呆板吗，
能不能纯脚本的情况下距离用上次消息时间的长短做概率判断，十分钟一次，10 分钟百分之多少的增加，到几个小时到 100%。
期间发生对话就重置到 0%…触发了就叫醒一次」。

## 决策过程（数值是他定的，不是我猜的）

| 他的决定 | 落地 |
| --- | --- |
| 每格 3% | `proactive_dm_step_pct: 3`（每 10 分钟一格） |
| 静默窗 00:30–07:00 | `proactive_dm_quiet: "00:30-07:00"`，窗里**不涨也不触发** |
| 概率不清空 | 窗里冻结：昨天 00:30 停在 40% → 今天 07:00 从 40% 接着涨（有测试钉住他原话） |
| 触发后归零、**不要冷却** | `note_fire()` 只归零；不加任何最小间隔（他说偶尔连发他接受） |
| 早上 7:20 那条当早安 | 从 40% 恢复后平均 ~20 分钟触发 ≈ 07:20，保留 |
| 群聊不做 | 主人随后明确「**群的保持原样就好，现在这个主动起头这个功能不往群搞**」→ 只做私聊；代码里加了"永不进群"护栏（挡群号 + `test_never_fires_into_a_group`），草案留在 `chat-layer/PLAN-主动插话-群聊.md`（决定记录，不是待办） |

**模拟值**（+3%/10min、醒着 14 小时没人理）：保底 **5h30m** 必触发、典型 **1h10m** 就开口、
平均间隔 ~112 分钟、约 **7 次**。他选 3% 想要「别烦」——要注意 3% 主要把**保底**推晚，典型时间对步长不敏感
（2% → 1.33h / 5% → 0.83h），真实用着还是烦就降步长。

## 实现

| 文件 | 内容 |
| --- | --- |
| `plugins/onebot/proactive.py`（新，~200 行） | `ProactiveRamp` 纯逻辑：静默窗解析（含跨零点）、`on_activity()` 归零、`advance()` 按整格补（窗内不涨）、`prob()`、`roll()`、`note_fire()`、`awake_minutes()`、`build_text()`。**不碰网络、不碰 LLM。** |
| `adapter.py` | 看门狗里挂 `_proactive_check()`（不新增 cron）；私聊入站/出站都 `_proactive_activity()` 归零；触发 → `_dispatch(..., is_group=False, trigger="proactive")`；状态落 `onebot-proactive.json`（重启不丢格数） |
| `config.yaml` | `proactive_dm_enabled: true` / `proactive_dm_step_pct: 3` / `proactive_dm_tick_min: 10` / `proactive_dm_quiet: "00:30-07:00"`（默认关，线上开） |

**她看到的注入**（`build_text()`）：
```
[OneBot 主动私聊回合 · source=qq-dm-proactive · 沉默 X · 触发时 p=Y% · 今天你第 N 次主动开口 · 距你上次主动开口 Z]
—— **这一轮没人跟你说话，是你自己想起他了**（现在 HH:MM）。他已经 X 没出声。你想说什么就说什么…
真没什么想说的，回 `[SILENT]` 就不发。
```
主人要求的两个数（沉默多久 / 在多少概率被掷中）都在；另加「今天第几次」「距上次自己开口多久」防她说重话。
跨静默窗时会额外标一句「（中间隔了一夜/静默窗，醒着的那段是 …）」，免得她早上说「你仨小时没理我」。

**私聊的 `[SILENT]`**：只在**主动回合**生效（`_proactive_turn`，900s 内），普通私聊回合不允许装死（他问了就得答）——有测试两边都钉了。

## 收尾补的两处（同样是"不做就会静默失效"的坑）

1. **冷启动播种**（`_proactive_seed_owners()`）：`_proactive` 是空的时候，重启后就「得等他先说话才开始计时」——
   等于重启一次、主动发言静默到下一次对话。现在启动时给配置里的主人私聊播一个「现在」（时钟从启动算起，不会一上来就触发）。
2. **启动即落盘**：状态文件一启动就生成，进程再重启也不丢时钟。

**线上实测**（重启 `gateway-chat` 后自动生成）：
```
/opt/data/profiles/chat/onebot-proactive.json
{"fires": 0, "chats": {"<OWNER_QQ>": {"ticks": 0, "last_activity_ts": 1791056025, "last_tick_ts": …, "fires_today": 0}}}
```
日志里没有 `proactive` 相关报错。

## 没做的

* **群聊**：不做（主人明确否掉）。草案 `chat-layer/PLAN-主动插话-群聊.md` 留作决定记录；
  群聊那条链路（免费闸 / @ 唤醒 / 窗口 / 群记忆）**一行没改**。
* 旧的固定时刻 cron「心跳-主动找主人说话」（12:30/17:30/21:30）**仍是禁用状态**，没删；
  它跟新斜坡是两套机制，要复用/删掉说一声。
* 每天总量上限：**没设**（主人只否掉了冷却，没提上限；实测 14 小时约 7 次）。

  对话归零、触发归零、没有冷却、awake_minutes 排除静默窗、注入文本含两个数；
