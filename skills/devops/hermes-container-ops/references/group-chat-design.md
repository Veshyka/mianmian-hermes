# 群聊机制设计（潜水 / 主动插话 / 被 @ 必答 / 记忆不污染）

适用：QQ 小号经 OneBot 适配器（`hermes_onebot`）进群。下面是**已定案的设计规则**，实现前先照它，再谈代码。

## 状态机（最关键，主人亲自纠正过）

| 状态 | 进入 | 行为 | 退出 |
|---|---|---|---|
| **潜水态**（默认） | 初始 / 退出对话态 | 全量收进群窗口，不发言，**0 次 LLM 调用** | 被 @ 或点名，或她插话后有人回应她 |
| **对话态** | 被 @ / 点名，或她插话后有人接 | **必须接着聊**，不需要每次 @ | 无人接她超过「静默退出窗口」（默认 5 分钟）**且**群内连续「无关消息条数」（默认 15 条）与她无关 |
| **冷却 / 频率闸** | 只在「潜水态 → 主动插话」这条路径上生效 | 限制主动开口频率 | — |

两条硬规矩：

1. **@ 必答是硬规则**：任何状态都能唤醒，不走概率骰子；但要有 10 秒级合并与每分钟上限，防有人连点她几十下。安静时段只**降低主动插话概率**，**不阻止 @ 唤醒**。
2. **冷却 / 「自己话多」扣分只能作用在「潜水→主动插话」路径上，对话态内一律不生效。** 主人原话：*「刚说过话如果是连贯对话肯定不能突然消失吧」*。把它加到对话态上，症状就是「聊着聊着人没了」——这是设计缺陷，不是调参问题。跟随窗口（她说完后 1~3 分钟内有人对她说话就必续）是这条的实现。

## 三级门控（省钱的唯一办法）

① **规则层**（零成本，永远先过）：冷却、自身发言频率、群活跃度、安静时段、是否被点名/引用。
② **概率层**：低频随机，频率上限按体感调。
③ **小模型判定**：只对候选判「该不该接 / 往哪接」，判不出＝不接（宁可不说话）。要给**独立端点**，别跟抽取抢同一个 `--parallel 1` 槽。

**门控必须做在适配器层、发生在 LLM 之前**：否则群里**每来一条消息就烧一次整轮 prompt**（本机实测整轮 ~21k token 量级）。这是成本红线，不是优化项。

⚠️ 别指望 embedding 模型顶替门控小模型（说话/判别两头实测都不成立），见 `local-llm-ops` 技能「已知陷阱」。

## 三层记忆：连贯 ≠ 入库

1. **连贯层**：每个群一个**滚动窗口**（最近 100~200 条，含发送者昵称、时间、`[图片]`/`[表情]` 占位）。只在群上下文里，唤醒时作为材料给她看；**绝不写主记忆库**。窗口要有条数 + 总字节双重上限，落盘位置放 profile 数据目录（重建不丢）。
2. **长期层**：**只有她自己主动判定「有意义」才写**，并打来源标签（如 `source=qq-group`），以后能分清哪句来自群。
3. **默认零入库**。

**为什么不能反过来（先全量入库、再挑着删）**：污染在写入那一刻就发生了，事后删不干净——主库是给私聊用的，串进群里的闲聊会让两边的召回都变脏。要从**源头**堵。

## 表情包分两阶段

- **阶段一（只屯）**：收到即下载（图片链接会过期，必须当场落盘）、内容哈希去重、可选本地 VLM 描述归档（文本进窗口，二进制另存）。
- **阶段二（能用）**：验通后才允许她发（按相似度挑一张）。

可抄的两种现成做法（都值得读，但只抄第一种）：
- **麦麦bot（Mai-with-u/MaiBot）**：潜水＝**纯规则评分、发生在 LLM 之前**（@ 直通 + 闲置压力 + 自己话多惩罚）→ 不触发就不花钱；表情包＝**收到消息时顺手入库** + 内容哈希去重 + VLM 描述成文字、二进制即丢，发的时候按相似度取一张。
- **qq-bridge（Derpyu520/qq-bridge，建在 OneBot v11 上，协议与我们同源）**：群消息**全量收但不唤醒引擎** + 低频概率 + 每分钟唤醒上限；表情包走**同步 QQ 收藏库**（有 API 依赖，别抄这条）。

## 参数与边界

- **所有阈值集中成一张参数表**（跟随窗口、退出条件、频率上限、概率、安静时段），改配置不改代码——否则主人每次按体感微调都要动代码。
- 边界写进人格与适配器：群内**不接活**（派活回私聊/干活门）、不发散、不泄露内部与凭据；失败降级＝宁可不说话也不发疯。
- 多群隔离：每群一套窗口/状态/参数，互不影响。
- **群号白名单**：主人自己开的群不必加（他明确说不要）；**但要在文档里留一句**：日后如果有别人能把 bot 拉进别的群，加一条「只认这个群号」即可。
- 私聊侧：`dm_policy: allowlist` + `allow_from: [<主人 QQ>]` 已经等于「只跟主人聊」，别人发她一律不理——这是现行状态，别动。
- **实施分步**：B（群消息只收不说，0 次 LLM、记忆隔离可机制证明）→ C1（@ 必答 + 群上下文）→ C2（主动插话三级门控 + 状态机）→ C3（表情包使用）。每步独立验收、**一行开关能全关**。
